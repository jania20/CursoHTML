# Curso de HTML - Platzi

Este repositorio contiene los ejercicios y prácticas realizadas durante el curso de HTML de Platzi. El curso se enfoca en aprender desde lo básico hasta elementos más avanzados para la creación de páginas web.

## Descripción
Se trabajaron conceptos fundamentales de HTML como la estructura de una página web, etiquetas básicas, enlaces, imágenes y formularios.

## Temas vistos
- Estructura básica de HTML
- Etiquetas de texto (h1, p, strong, etc.)
- Enlaces e imágenes
- Listas ordenadas y desordenadas
- Formularios HTML
- Inputs, checkbox y select

## Objetivo
Aprender a construir páginas web estáticas con HTML y comprender la estructura base del desarrollo web.
